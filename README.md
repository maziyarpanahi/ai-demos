# AI demos

Small, readable AI demos that use an OpenAI-compatible API.

Each demo is self-contained. Choose the model host yourself: a local server
such as Ollama, LM Studio, or llama.cpp, or a hosted service such as
OpenRouter.

## Demos

- [Draw object boxes with Qwen3.8](demos/qwen3.8-vision-boxes/README.md)

## Principles

- no provider-specific SDKs;
- no API keys, private endpoints, logs, or model receipts;
- no social-media layouts or bundled result images;
- one short README and one runnable entry point per demo.
